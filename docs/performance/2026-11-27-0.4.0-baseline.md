# 0.4.0+ three-engine performance baseline — 2026-11-27

Clean before/after baseline for the 0.4.0+ optimizations (Wave A hot-path, Canvas state caching, single-line exact probe reuse, ASCII `Float64Array` tabular calibration, and single-pass / reverse-greedy multiline solver) across Chromium, Firefox, and WebKit.

## Capture setup

- Base revision: `07ab4d0d7c42c6309fc601244faf22d5d4d5a6d8` (`v0.3.3`, parent of `5a16096`, source digest `e67c91017f2c...`).
- Candidate revision: `d8af048` (`HEAD`, source digest `791bc6fa200e...`). Both revisions run against the same harness (version 2) and pinned `linebreak` `2.0.0` runtime (the runner shims `v0.3.3`'s default import when `--ref` is used).
- Workload: 20 scenarios per engine covering 200-string cold/warm batches for `regular` (`fast`, `exact`), `tabular` (`fast`, `auto`), `repeated` (`fast`), `mixed` (`fast`), `multiline2` (`fast`, `exact`), and `multiline3` (`fast`, `exact`). Seven raw samples × 25 batch repetitions per sample; values below are medians in milliseconds per 200-string batch.
- Machine: Linux x64 (`AMD EPYC 9B45`), exclusive `slotfather` lease (`package-kit heavy all`).
- Raw pairs:
  - Chromium 159.0.8154.6: [before](before-0.4.0-chromium.json) / [after](after-0.4.0-chromium.json)
  - Firefox 159.0 (Playwright bundled): [before](before-0.4.0-firefox.json) / [after](after-0.4.0-firefox.json)
  - WebKit 27.2: [before](before-0.4.0-webkit.json) / [after](after-0.4.0-webkit.json)
